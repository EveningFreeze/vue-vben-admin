# Suguard — AI 智慧学习平台 · 项目作品文档

---

## 一、项目详情及使用方式

### 1.1 项目概述

**项目名称：** Suguard（Study + Guard，AI 学习守护平台）

**项目定位：** Suguard 是一个面向中学生、大学生及考研人群的 **AI 驱动智慧学习平台**，覆盖英语学习、中文文学素养提升、学术研究三大领域。平台以"AI Learning OS（AI 学习操作系统）"为核心理念，将传统分散的学习工具整合为统一的学习中枢，通过大模型 AI 技术实现个性化学习诊断、智能批改、场景化对话训练等功能。

**开发团队：** 海底一队

**技术架构：** 基于开源企业级前端框架 **vue-vben-admin v5.6.0** 进行深度二次开发，采用 Vue 3 + TypeScript + Vite + Pinia 技术栈，UI 使用 Ant Design Vue + Tailwind CSS v4，数据可视化使用 ECharts v6.0.0，AI 能力通过统一服务层接入通义千问 / OpenAI / 自定义端点的大模型 API。

### 1.3 使用方式

#### 环境要求

- **Node.js** ≥ 20.19.0
- **pnpm** ≥ 10
- 现代浏览器（Chrome / Edge / Firefox）

#### 安装与启动

```bash
# 1. 克隆项目
git clone <repository-url>
cd vue-vben-admin

# 2. 安装依赖
pnpm install

# 3. 启动开发服务器（Ant Design Vue 版本）
pnpm -F @vben/web-antd dev

# 4. 构建生产版本
pnpm build

# 5. 代码检查
pnpm lint
```

#### AI 功能配置

平台 AI 功能通过 **API 设置面板** 统一配置，支持三种方式：

1. **UI 面板配置（推荐）**：在英语作文批改页面右侧的 "API 设置面板" 中选择提供商（通义千问 / OpenAI / 自定义）、填入 API Key 和模型名称，配置自动保存到浏览器 localStorage。
2. **环境变量配置**：在项目根目录 `.env` 文件中设置 `VITE_LLM_API_URL`、`VITE_LLM_API_KEY`、`VITE_LLM_MODEL`。
3. **免配置使用**：不配置 AI 接口时，系统自动使用内置启发式算法进行评分和分析，核心学习功能不受影响。

#### 数据存储

当前版本所有用户数据（学习进度、XP、成就、AI 配置、笔记、作文历史等）均存储在浏览器 **localStorage** 中，无需后端服务即可完整体验全部功能。

## 二、项目亮点

### 亮点一：从页面集合到 AI Learning OS 的架构升维

Suguard 不是简单的学习工具堆砌，而是经过深思熟虑的 **三层架构设计**：

```
┌──────────────────────────────────────────────┐
│              平台统一层 (Platform Layer)       │
│  学习中心 · 统一XP · AI秘书 · 番茄专注 · 热力图    │
├──────────────────┬───────────────────────────┤
│   英语学习引擎     │     中文文学素养引擎         │
│  11个功能页面      │     12个功能页面           │
│  英语XP/成就系统   │     中文XP/成就系统         │
├──────────────────┴───────────────────────────┤
│              共享基础设施层 (Shared Layer)      │
│  AI服务层 · LLM配置 · 统一画像 · 设计令牌         │
└──────────────────────────────────────────────┘
```

**核心设计决策：**
- **模块独立 + 平台聚合**：英语和中文各自维护独立 XP/成就系统，学习中心通过 `useSgProfile` 跨模块聚合，形成统一的用户学习画像。这避免了"一刀切"的耦合，同时保留了未来扩展新模块的灵活性。
- **Composable 架构**：全部业务逻辑封装为 Vue 3 Composables（`useGamification`、`useAIService`、`useSpeech` 等），视图层极薄，测试和复用友好。
- **设计令牌体系**：英语模块采用蓝靛科技风（`en-*` CSS 变量），中文模块采用紫金国风（`chinese-*` CSS 变量），学习中心采用中性学术风（`sg-*` CSS 变量），三套视觉主题统一在 Tailwind CSS v4 框架下。

### 亮点二：真正的 AI 深度集成，而非"套壳"

平台实现了 **6 大 AI 落地场景**，每个都有真实的大模型调用架构和本地智能回退：

| AI 场景 | 实现方式 | 技术深度 |
|---------|---------|---------|
| **AI 作文批改** | 六维/五维评分 + 结构化 JSON 输出 + 雷达图可视化 | 支持流式 SSE + 非流式双模式，三层回退策略（API → 环境变量 → 启发式算法） |
| **AI 语伴对话** | 3 种模式 × 流式对话 | 6 个预设场景（含系统角色扮演 Prompt），Web Speech API 跟读评分 |
| **AI 古人对话** | 4 位历史人物个性化 Prompt | 每位人物独立 System Prompt，模拟其性格与语言风格 |
| **AI 学习诊断** | 结构化 JSON 诊断报告 | CEFR 六级映射 + IELTS 九分预估 + 30 天 AI 定制提升路径 |
| **AI 论文分析** | 结构化论文拆解 | 自动提取摘要/关键词/术语/难句/生成测验 |
| **AI 学习秘书** | 跨模块数据综合分析 | 聚合双模块学习数据生成个性化建议 |

**技术保障：**
- 所有 AI 调用统一经过 `useAIService` 服务层，支持 **Tongyi（通义千问）/ OpenAI / 自定义 OpenAI 兼容端点** 三类提供商
- 每个 AI 场景都内置 **本地启发式回退算法**，无 AI 接口时仍可完整体验功能（作文启发式评分误差控制在 ±3 分内）
- 流式响应支持 SSE 实时解析，用户体验流畅

### 亮点三：完整的游戏化成长体系

平台构建了业内领先的 **双层游戏化系统**：

**数值体系：**
- XP 等级公式：`Level = floor(sqrt(XP / 100)) + 1`（1级=0XP, 2级=100XP, 3级=400XP, 5级=1600XP...）
- 每日签到奖励：`10 + min(连续天数 × 5, 50)` XP
- 多途径 XP 获取：签到（10+）、学习时长（每30分钟10XP）、作文提交（50XP）、AI 诊断（30XP）、专注完成（20XP）、成就解锁（20-500XP）

**成就系统：**
- 英语模块：7 个成就（初次打卡/七日之约/月满勤/百词斩/测验达人/初试锋芒/学海无涯）
- 中文模块：12 个成就（继承英语基础 + 诗词鉴赏家/古文大家/闯关达人/学术新秀/精读之星等）

**视觉反馈：**
- RPG 九阶成长路线图（启蒙→诗词基础→古文入门→文学鉴赏→经典研读→学术阅读→学术写作→研究能力→导师级），含图标/名称/副标题/XP需求/路径/技能列表
- 学习热力图（GitHub Contribution Graph 风格，181天）
- SVG 环形番茄钟进度条

### 亮点四：Vue 3 现代化工程实践

- **TypeScript 全量覆盖**：所有 Composable、API 层、路由配置均使用 TypeScript，通过 `vue-tsc` 严格类型检查
- **Monorepo 架构**：基于 pnpm workspaces + Turborepo，共享 packages（@core / effects / 共享工具），支持同时构建多 UI 库版本（Ant Design / Element Plus / Naive UI / TDesign）
- **ECharts v6.0.0 树摇优化**：选择性注册 Bar/Line/Pie/Radar 四种图表类型，CanvasRenderer 渲染，避免全量引入
- **规范工程化**：ESLint + Prettier + Stylelint + commitlint + lefthook Git hooks + czg 交互式提交，保证代码质量一致性

### 亮点五：差异化特色功能

| 功能 | 同类产品对比 | Suguard 优势 |
|------|------------|-------------|
| 文学图谱 | 无同类功能 | 五合一体：知识图谱（可点击节点展开）+ 九段文学时间轴 + 三栏文本对读（原文/现代译文/English）+ 飞花令（poetryDB校验）+ 名句挑战（20题） |
| 古文阅读 | 通常只有阅读 | 三大模式：阅读 + 断句练习 + 翻译训练，含拼音标注和 AI 解析 |
| AI 古人对话 | ChatGPT 角色扮演 | 4位古人独立 System Prompt 角色扮演（孔子/苏轼/庄子/鲁迅），融入文学知识体系 |

### 3.1 AI 服务技术架构

```

│                  视图层 (Views)                │
```

### 3.2 AI 接口调用方式

**（1）流式对话（Stream Chat）**

使用于 AI 语伴、AI 导师场景，通过 `fetch()` 发送 POST 请求，解析 SSE（Server-Sent Events）流：

```typescript
// 核心实现
const response = await fetch(apiUrl, {
  method: 'POST',
  headers: { 'Content-Type': 'application/json', 'Authorization': `Bearer ${apiKey}` },
  body: JSON.stringify({ model, messages, stream: true, temperature: 0.7, max_tokens: 2048 }),
});

// SSE 逐行解析 "data: {...}" 和 "[DONE]" 信号
// 通过回调 onChunk / onDone / onError 实时反馈
```

**（2）结构化 JSON 调用**

使用于学习诊断、论文分析场景，要求 LLM 返回严格 JSON 格式，内置自动提取逻辑：

```typescript
// callStructured<T>() 方法
// 1. 发送系统提示 + 用户提示到 LLM
// 2. 解析响应中的 JSON（处理 markdown 代码块和裸 {} 格式）
// 3. 返回类型安全的 T 对象
// 4. 失败时自动回退到本地算法
```

**（3）作文评分 API**

六维度英语评分（语法/词汇/连贯/风格/内容/结构）+ 五维度中文评分（论点/结构/规范/创新/资料），返回结构化评分 + 修改建议 + 词汇分析。

### 3.4 智能回退与容错

每个 AI 调用点均实现 **三层回退策略**：

```
优先级 1: localStorage 配置 (sg-llm-config)
    ↓ 失败
优先级 2: 环境变量 (VITE_LLM_API_URL/KEY/MODEL)
    ↓ 失败
优先级 3: 本地启发式算法
    - 英语作文: 基于词数/词汇多样性/平均词长/句子数的评估
    - 中文写作: 基于字符数/段落数/句子数的评估
    - 诊断报告: 基于已存储能力数据的本地生成
```

错误处理覆盖：401（密钥无效）、429（频率限制）、网络超时（30s AbortController）、响应解析异常。

## 七、基于原项目的优化说明

### 7.1 基础项目

本项目基于开源框架 **vue-vben-admin v5.6.0**（GitHub: vbenjs/vue-vben-admin）进行深度二次开发。原项目是一个通用企业级后台管理框架，提供登录认证、权限管理、动态路由、多标签页、国际化等基础后台功能。

### 7.2 优化与新增部分

#### 一、全新业务模块（100% 自研）

在原框架仅提供基础后台模板的基础上，**从零构建了完整的 AI 智慧学习业务系统**：

| 新增内容 | 数量 | 说明 |
|---------|------|------|
| 功能页面 | **26 个** | 覆盖英语学习、文学素养、学习中心、学术研究四大模块 |
| 共享组件 | **26 个** | 模块专属布局、卡片、面板、英雄区、签到、发音、排行榜等 |
| 路由模块 | **3 个** | `english.ts`、`chinese.ts`、`learning-center.ts` |
| Composable 函数 | **8+ 个** | AI 服务、LLM 配置、游戏化、语音合成、字典查询、学习计时等 |
| API 模块 | **1 个** | `essay.ts` AI 作文评分接口 |

#### 二、AI 服务体系（100% 自研）

原项目不含任何 AI 能力。我们新增了完整的 **三层 AI 服务架构**：

```
useLLMConfig (配置层)
    ↓
useAIService (调用层: streamChat / callJSON / callStructured)
    ↓
模块级 AI 功能 (6 大场景 × 12+ Prompt 模板)
```

#### 三、游戏化系统（100% 自研）

原项目无任何游戏化机制。我们新增了 **双层游戏化体系**：

- **模块级**：英语 XP + 7 成就 / 中文 XP + 12 成就，localStorage 独立持久化
- **平台级**：`useSgProfile` 跨模块统一画像，聚合 XP/等级/连胜/成就
- **数值体系**：XP 等级公式、每日签到奖励曲线、连续打卡加成、成就阶梯解锁

#### 四、视觉设计体系（100% 自研）

- 英语模块：蓝靛科技风（`en-*` 设计令牌）+ 渐变玻璃态卡片
- 中文模块：紫金国风（`chinese-*` 设计令牌）+ 仿古籍排版
- 学习中心：中性学术风（`sg-*` 设计令牌）+ 现代 Dashboard 布局

三套视觉体系均基于 Tailwind CSS v4 构建，通过 CSS 自定义属性实现主题切换。

#### 五、数据可视化增强

在原项目已有的 ECharts 集成基础上：
- 升级到 ECharts v6.0.0，启用树摇优化（仅引入需要图表类型）
- 新增雷达图、热力图、分段柱状图等图表类型到学习诊断和能力评估场景
- 自研 SVG 环形进度条（番茄钟），纯 CSS 实现学习热力图

#### 六、架构优化

| 优化项 | 原项目 | 优化后 |
